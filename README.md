🕌 Project Name

Andalus Civilization | Interactive Educational Website

📖 Description

An interactive educational website that presents the history and achievements of the Andalusian civilization through a modern and responsive interface. The project combines multimedia, smooth animations, image sliders, and interactive UI elements to create an engaging learning experience.

✨ Features
Responsive design for all screen sizes.
Mobile navigation menu.
Animated loading screen.
Scroll progress indicator.
Hero section.
Interactive city showcase.
Educational video player.
Scientists section with hover overlays.
Image gallery slider.
Smooth scrolling navigation.
Contact section.
Animated transitions and scroll effects.
